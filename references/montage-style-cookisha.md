# Референс монтажа: «Привет, Саша» (@cookisha_)

Видео-визитка / интро, 36.6 с, 1440×1080 (4:3), 30 fps, с аудио.

## Стиль
- **Фон:** почти белый (#F5F3F7-ish) между кадрами; финал — тёмно-серый экран.
- **Типографика (kinetic typography):** жирный сжатый гротеск, **красный** (#D0102A-ish),
  плотный кернинг, буквы налезают друг на друга. Слова появляются по одному под ритм речи/музыки.
- **Мелкий подтекст:** маленький чёрный текст по центру («я мечтаю купить свою», «и начать снимать»),
  следом — крупное красное ключевое слово («первую камеру», «ещё больше»).
- **Слово, разбитое по слогам** вокруг видео: «НЕС-КОЛЬ-КО … ЧА-СОВ», «ПУ … ТИ».
- **Огромный шрифт на весь кадр** для имени («САША» выходит за края).
- Текст поверх полноэкранного видео — белый («путешествия», «людей», «истории»), иногда красный внизу («МОНТИРОВАТЬ»).
- Постоянная плашка-вотермарк: иконка Instagram + `@COOKISHA_` в углу.

## Приёмы
- Фото/видео в **скруглённых карточках**, повёрнутых под углом, «влетают» рядом с текстом.
- Коллаж из 4 маленьких карточек вокруг фразы.
- Чередование: белый экран с текстом ↔ полноэкранное видео (самолёт, горы, город, граффити).
- Голова-вырезка в **красной звезде-взрыве** («я видеограф? или монтажёр?»).
- Скриншоты интерфейсов (монтажка, сайты) как карточки — «процесс работы».
- Повороты/наклон камеры, мягкий blur/motion-blur на появлении слов («посмотрим)» с размытием).
- Видео с зелёной лампой / ноутбуком — «за поиском нужной музыки».

## Структура (тайминг)
| Время | Блок |
|---|---|
| 0–2 с | «привет, меня зовут САША» + фото-карточки |
| 2–5 с | «обожаю снимать» + путешествия |
| 6–10 с | «я мечтаю купить свою первую камеру и начать снимать ещё больше: путешествия, людей, истории» |
| 11–15 с | «мне [всё]… а ещё я обожаю МОНТИРОВАТЬ / когда я открываю ноутбук, я теряю счёт» |
| 16–19 с | «проводить несколько часов за поиском нужной музыки» |
| 19–23 с | «я видеограф? или монтажёр? / ни тот, ни другой… в моём (портфолио) мало кейсов, пока что» |
| 24–29 с | «и я только в начале своего ПУТИ, но думаю, что творческое начало во мне точно есть» (горы) |
| 29–31 с | «а что будет дальше — посмотрим)» |
| 31–36 с | аутро: `cookisha` → тёмный экран, лого Instagram (цветное → белое) + `@COOKISHA_` |

## Как воспроизвести
Темп ~1 смена каждые 0.5–1 с, жёсткие склейки без переходов, слова — pop-in по одному.
Палитра: белый / красный / чёрный, цвет даёт только видео. Формат 4:3 или 9:16.
